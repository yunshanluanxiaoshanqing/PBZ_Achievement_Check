# PBZAchDiag — 影之刃零 · 成就检测（只读）

一个 UE4SS 小模组：在游戏里读出「当前存档记录了哪些成就」，告诉你到底还差哪一条。

适用于 **Phantom Blade Zero（Steam AppID 4115450）**。

> 起因：回档之后 Steam 显示 65/66，最后一个成就「逆天改命」怎么都不弹。
> 原因是游戏在**存档内部**维护了一份成就记录，回档把其中一条抹掉了；
> Steam 侧仍是 65 条，于是「完成其余全部成就」的判定永远差一个。
> 这个模组只负责把那份记录读出来，不修改任何东西。

## 安装

1. 安装 [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS)（本模组在 **v3.0.1** 上测试）。
2. 把整个 `PBZAchDiag` 文件夹放到：

   ```
   <游戏目录>\platform\steam\ue4ss\Mods\PBZAchDiag\
   ```

3. 确认目录里有 `enabled.txt`（空文件即可），UE4SS 会据此加载。

## 使用

1. 进入游戏，载入存档。
2. 等界面稳定几秒，按 **F7**（F6 只是提示）。
3. 检测完成后会生成两个文件：
   - 游戏根目录 `PBZ_Achievement_Check.txt` —— 文本报告；
   - 桌面 `影之刃零-成就检测.png` —— 一张图片说明。

报告里的缺失项形如：

```
【缺失成就】
ACH_053  兵不血刃
```

看到缺哪条，就在**当前这个存档**里重新完成它的条件；完成后按 F7 复查，缺失应为 0。

> 生成图片时游戏会卡顿几秒（要拉起 PowerShell），属正常现象。
> 如果自动生成图片失败（没有 PowerShell 权限等），双击 `生成图片.cmd` 手动生成。

## 安全

- 只做 `FindAllOf` + 属性读取，**不修改存档**、**不调用** `UnlockAchievement` / `ResetAchievements` 等接口。
- 不改游戏文件，删除文件夹即可完全卸载。
- 输出内容仅为本机成就状态，不上传任何数据。

## 已知问题

- 依赖 UE4SS；UE4SS 本身在某些配置下会导致游戏崩溃，与其它模组混用时尤其明显。若崩溃，先只保留本模组测试。
- 游戏对 UE4SS 的对象枚举较敏感：**不要在模组加载阶段查找对象**，本模组已改为按键触发。
- 只读取 `ACH_001`–`ACH_065` 的记录；`ACH_066` 是「完成其余全部成就」的元成就，单独显示其记录状态。

## 目录

```
PBZAchDiag/

├─ 生成图片.cmd          手动生成图片（自动生成失败时用）
├─ README.md
└─ LICENSE              MIT
```
